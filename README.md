# 🤖 بات سیگنال کریپتو تلگرام

ربات تلگرام برای اسکن بازار ارزهای دیجیتال و ارسال سیگنال خرید/فروش دقیق.

## ✨ ویژگی‌ها

- **📊 تحلیل Order Flow** - جریان خرید/فروش و عدم تعادل بازار
- **💧 اسکن Liquidity** - شناسایی نواحی نقدینگی، حمایت/مقاومت، order book walls
- **🐋 اسکن نهنگ‌ها** - شناسایی فعالیت نهنگ‌ها، ناهنجاری حجم، تحلیل CVD
- **🎯 سیگنال دقیق** - Entry، Stop Loss، Take Profit (3 هدف)
- **🛡️ مدیریت ریسک** - حداقل Risk/Reward 2:1، حداکثر استاپ 5%
- **📈 حداقل 10% سود** - فقط سیگنال‌هایی که پتانسیل 10%+ سود دارن

## 📋 نیازمندی‌ها

```
Python 3.8+
```

## 🚀 نصب

1. **نصب کتابخانه‌ها:**

```bash
pip install -r requirements.txt
```

2. **دریافت توکن بات تلگرام:**
   - به [@BotFather](https://t.me/BotFather) در تلگرام پیام بده
   - دستور `/newbot` رو بزن
   - اسم و یوزرنیم بات رو وارد کن
   - توکن رو کپی کن

3. **دریافت چت آیدی:**
   - به [@userinfobot](https://t.me/userinfobot) پیام بده
   - چت آیدی عددی خودت رو کپی کن
   - (یا آیدی کانال/گروه مقصد)

4. **تنظیم فایل config.py:**

```python
TELEGRAM_BOT_TOKEN = "توکن شما"
TELEGRAM_CHAT_ID = "چت آیدی شما"
ADMIN_IDS = [123456789]  # آیدی عددی خودت
```

5. **اجرا:**

```bash
python main.py
```

## 🎯 روش تحلیل

### 1. Order Flow (جریان سفارشات)
- محاسبه حجم خریدار (taker buy) در برابر فروشنده
- نسبت دلتا (buy/sell ratio)
- شناسایی کندل‌های حجم بزرگ (anomalies)
- روند دلتا در 10 کندل اخیر
- تحلیل تریدهای تیک (tick-by-tick)

### 2. Liquidity (نقدینگی)
- شناسایی swing highs/lows → حمایت و مقاومت
- تجمیع سطوح نزدیک به هم
- شناسایی equal highs/lows (نواحی نقدینگی)
- تحلیل دیوارهای order book (bid/ask walls)
- محاسبه عدم تعادل order book

### 3. Whale Scanner (اسکن نهنگ‌ها)
- شناسایی تریدهای بزرگ (بالای آستانه)
- محاسبه جریان خالص نهنگ‌ها (net flow)
- ناهنجاری حجم (Volume Anomaly Detection)
- تحلیل Cumulative Volume Delta (CVD)
- واگرایی CVD با قیمت

### 4. موتور سیگنال
- ترکیب امتیاز تمام تحلیل‌ها
- رأی‌گیری جهت (LONG/SHORT)
- محاسبه Entry، Stop Loss، Take Profit
- حداقل امتیاز 70 از 100
- حداقل Risk/Reward 2:1
- حداقل سود مورد انتظار 10%

## ⚙️ تنظیمات قابل تغییر (config.py)

| تنظیم | پیش‌فرض | توضیح |
|-------|---------|-------|
| `SCAN_INTERVAL` | 300 ثانیه | فاصله بین اسکن‌ها |
| `MIN_TARGET_PROFIT` | 10% | حداقل سود مورد انتظار |
| `MIN_RISK_REWARD` | 2.0 | حداقل Risk/Reward |
| `MAX_STOP_LOSS_PCT` | 5% | حداکثر درصد استاپ |
| `MIN_24H_VOLUME` | 50M | حداقل حجم روزانه ارز |
| `WHALE_TX_THRESHOLD` | 1M | حداقل حجم ترید نهنگ |
| `MIN_SIGNAL_SCORE` | 70 | حداقل امتیاز برای ارسال |

## ⚠️ هشدار

این ربات سیگنال‌های مبتنی بر تحلیل تکنیکال تولید می‌کنه و **نظر سرمایه‌گذاری نیست**. مسئولیت کامل معامله با شماست. بازار کریپتو نوسان بالایی داره و هیچ سیگنالی 100٪ دقیق نیست. همیشه:
- مدیریت سرمایه رعایت کن
- از حد ضرر استفاده کن
- بیش از حد توان خودت ریسک نکن
